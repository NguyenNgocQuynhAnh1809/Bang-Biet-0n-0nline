🔒 Setup AI Chatbox Config

📋 Hướng dẫn sử dụng Cloud Function (BẢO MẬT):
Deploy Cloud Function: firebase deploy --only functions
Lưu API key: firebase functions:config:set perplexity.key="YOUR_KEY"
Điền Function URL bên dưới
Bỏ trống API Key (không cần lưu trong Firestore)

✅ API key đã được lưu trong Firebase Functions Config (bảo mật)
